# 🔐 Caesar Cipher Brute Force Tool
A simple Python script that cracks Caesar cipher encrypted text by trying all 26 possible shifts. Using for simple CTF.

🚀 How It Works
Tries all 25 possible shifts (1-25)
Decrypts the text for each shift
Displays all results in a readable table
You identify which output looks like proper English (or French) 

🔍 Quick Start Guide
1. Run the script
python Simple_Caesar_Bruteforce.py

2. Input your encrypted text
